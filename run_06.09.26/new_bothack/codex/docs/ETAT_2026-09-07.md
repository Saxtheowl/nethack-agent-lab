# État du portage BotHack Python — 7 septembre 2026

Point établi le 7 septembre 2026 à 20:26 UTC.

## Résultat actuel

**Aucune ascension Python. Le Python ne joue pas encore une partie autonome complète.** Le travail avance sur un portage natif et ses comparaisons avec l’original, mais la chaîne de jeu et la stratégie sont encore incomplètes. L’objectif reste une vraie ascension sans mode wizard ni intervention humaine, avec les preuves conservées.

Tout le travail de cet agent est dans `codex/`. Les répertoires voisins appartiennent aux autres agents.

## Référence et environnement prêts

- Original : `krajj7/BotHack`, commit `70226b3c8ed12d29c64068aec0acc0ca71d57adf`.
- Jeu cible : **NetHack 3.4.3-NAO**, et non 4.3 ; révision historique `b60bd44c46ed263e89fcebafd5d7271c700446e9`.
- Original compilé avec un Java 8 local ; jeu historique compilé et exécutable localement.
- Oracle de comparaison : exécute les véritables fonctions Clojure, sans modifier les sources de référence.
- Le code Python du bot ne lance pas Java pour prendre ses décisions. Java sert aux outils de référence et d’export.

## Ce qui fonctionne déjà

Le portage contient environ **3 000 lignes Python**, hors données, tests et outils. Ce nombre n’est pas un pourcentage d’avancement.

- Analyse du terminal : grille, couleurs, état du personnage, inventaire et libellés d’objets.
- Synchronisation du scraper : marqueurs clavier, messages, questions, menus multipages et ordre des événements.
- Délégation par priorité, encodage des réponses et réponses de repli originales.
- Tables de 1 722 identités d’objets, 376 types de monstres et huit scripts Sokoban.
- Identification dynamique partielle : découvertes, prix, propriétés, élimination et réutilisation des noms.
- Commandes clavier des **44 types d’actions** ; premiers gestionnaires, notamment inventaire, nommage, prière et équipement simple. Les gestionnaires manquants signalent explicitement leur absence.
- Cartes persistantes, branches, règles de reconnaissance des niveaux spéciaux et **33 plans prédéfinis** exportés de l’original.
- Champ de vision, mémoire des monstres et calcul de fraîcheur des cadavres.
- Mise à jour de la carte sur une séquence de quatre écrans synthétiques, comparée à l’original.
- Premiers calculs de nourriture, poids, santé et utilité des objets.

## Ce qui manque pour l’ascension

1. Achever et relier la boucle d’événements, le transport du jeu et les mises à jour différées.
2. Compléter les effets des actions : déplacements, combat, exploration, identification, objets, conteneurs et transitions entre niveaux.
3. Compléter le modèle du joueur et les gestionnaires de messages du jeu.
4. Porter la stratégie `mainbot` dans son ordre de priorité original : survie, combat, équipement, exploration, quête, château, farming, invocation et plans élémentaires. **C’est encore une grosse partie du travail restant.**
5. Lancer des parties Python réelles, analyser les blocages et les morts, corriger les divergences, puis obtenir et conserver une ascension vérifiable.

Les tests locaux ne prouvent pas encore la fidélité de l’ensemble du bot. Aucun taux d’ascension Python n’est mesurable actuellement.

## Est-ce que 5 dollars chez Vast.ai aideraient beaucoup ?

**Pas beaucoup au stade actuel. Je recommande de garder ce budget pour les essais de parties.** Le blocage principal est le code restant à porter et à intégrer, pas un manque de calcul.

BotHack est un bot à règles. Le code présent n’utilise ni entraînement neuronal ni calcul GPU. Une grosse carte graphique n’accélérera donc pas directement ce portage. Plus tard, plusieurs cœurs CPU et suffisamment de RAM pourront servir à lancer plusieurs parties et plusieurs références en parallèle ; le gain réel devra être mesuré une fois la boucle autonome fonctionnelle.

Vast.ai loue principalement des instances GPU, avec des ressources CPU et RAM associées. Son coût combine calcul, stockage et transferts : sans choisir une offre précise, on ne peut pas annoncer honnêtement combien d’heures couvriraient 5 dollars. Sources officielles consultées : [présentation des instances](https://docs.vast.ai/guides/instances/overview), [tarification](https://docs.vast.ai/guides/instances/pricing).
