    Répartition depuis le 27/09 13h15 : seuls les agents Claude (et moi) tournent sur ce PC. Le dashboard, le recorder, les parties et les outils des agents (scripts/slotrun) passent sur le worker miniforum ; le PC ouvre juste un tunnel ssh vers 127.0.0.1:8766 et scripts/worker_sync.sh recopie les données (replays, journaux, ledgers) dans les deux sens. Les parties commencées sur ce PC y finissent (on ne déplace jamais une sauvegarde) ; chaque nouvelle partie démarre sur le worker.

    Les calculs lourds des agents (solveur de Sokoban, recherches) partent sur le worker miniforum via scripts/onworker (limite 8 Go, délai maximal). Un watchdog local tue tout helper Python qui dépasse 2,5 Go.

    Règles du jeu et de l’expérience

    • Jeu pur : NetHack 3.6.7 vanilla, Valkyrie naine (dwarf, female, lawful), aucun bot, pas de wizard/explore mode, pas de retour à une sauvegarde après une mort.
    • Chaque touche est choisie par un agent Claude après lecture de l’écran ; les helpers (travel, fight, rest, autoexplore…) ne font que des actions bornées qui s’arrêtent au moindre danger (perte de HP, faim, monstre inconnu).
    • Style : toutes les parties jouent en Astra (memory/astra-style.md, la méthode qui a ascensionné 1 fois sur 3, enrichie des leçons de nos morts). Les styles Tariru, Tariru v2 et Wish abuser ont été essayés puis arrêtés : voir le guide.
    • Garde-fous du harnais : alarme HP, refus des attaques sur les @ et les « e », blocage pendant Stone/Slime, pas de repos compté blessé.
    • Mémoire des agents : un journal par run (memory/run-N.md, memory/slotN-run-M.md) : état, objets identifiés, menaces, leçons. Les leçons remontent dans l’Historique.
    • Options : config/nethackrc — interface curses 144×36, number_pad, arrêt forcé sur les messages dangereux (Weak, deathly sick, stoning, strangulation, polymorph trap), confirmation pour #pray.
